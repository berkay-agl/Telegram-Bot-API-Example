# Telegram Bot API Öğrenme & Uygulama 

Bu depo, resmi [Telegram Bot Tutorial](https://core.telegram.org/bots/tutorial) dokümantasyonunu takip ederken adım adım geliştirdiğim testleri, pratikleri ve örnek kodları içermektedir. 

Telegram Bot API'sinin temel mekaniklerini kavramak amacıyla sıfırdan başlanarak her aşama ayrı dosyalarda modüler şekilde işlenmiştir.
